# source/Bindings

`ChartBindings.cpp` exposes CombinationCharts (native CST chart styles). `SimulationBindings.cpp` exposes CombinationBackend (simulation-only acquisition, timed rows and native adaptive PID). Bindings translate typed values; CST workflow/setting policy remains in reused CST code and explicit adapters. Hardware/server bindings are not exposed in this milestone.

Status: see the root README and PARITY_CHECKLIST.md for implemented versus pending work. A folder's presence does not mean its migration is complete.
